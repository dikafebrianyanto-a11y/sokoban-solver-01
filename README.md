A push-optimal Sokoban solver: it splits each generated level into its independent rooms, solves every room with push-based A* (minimum-assignment heuristic, deadlock pruning), and stitches the rooms together with hallway walks. Push-optimal on every practice level.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
